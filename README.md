## About Me

Hi, I'm **Matiur Rahaman**, a Full-Stack Developer who enjoys turning ideas into practical web applications. I work across the stack—from building responsive user interfaces and designing REST APIs to modelling data, implementing authentication and integrating external services.

I value clear code, maintainable architecture, useful documentation and user experiences that solve real problems.

- **Frontend:** React, TypeScript, JavaScript, Preact and Vite
- **Backend:** Node.js, Express.js, REST APIs and PHP
- **Databases:** MongoDB, Mongoose and MySQL
- **Integrations:** Socket.IO, Gemini API and third-party REST services
- **Engineering interests:** Authentication, role-based access control, real-time applications and business workflows
