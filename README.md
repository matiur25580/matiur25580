## 👨‍💻 About

Hi, I'm **Matiur Rahaman** — a Full-Stack Developer who enjoys creating practical web applications, intuitive interfaces and dependable backend workflows.

I like working across the product lifecycle: shaping an interface, designing APIs, modelling data, implementing authentication and connecting services into a cohesive application.

- **Frontend:** Building responsive interfaces with React, TypeScript and modern JavaScript.
- **Backend:** Developing REST APIs, authentication flows and server-side business logic with Node.js and Express.
- **Data:** Working with MongoDB, Mongoose and MySQL.
- **Product mindset:** Exploring real-world workflows across collaboration, recruitment, finance and operations.
- **Currently focused on:** Writing maintainable code, strengthening application security and improving end-to-end product quality.
