## 👋 About Me

Hi, I'm **Matiur Rahaman**, a Full-Stack Developer interested in building practical applications, intuitive interfaces and reliable backend workflows.

I enjoy working across the product lifecycle — from shaping user experiences and designing APIs to modelling data, implementing authentication and integrating services.

- **Frontend:** Responsive interfaces with React, TypeScript and modern JavaScript.
- **Backend:** REST APIs, authentication and server-side business logic with Node.js and Express.
- **Databases:** MongoDB, Mongoose and MySQL.
- **Integrations:** REST-based third-party services, Socket.IO and Gemini API.
- **Engineering focus:** Maintainable code, application security, clear documentation and end-to-end quality.
